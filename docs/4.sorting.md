# Sorting Algorithms


- Python uses Powersort for list.sort() and sorted() functions.

### Criteria for analysis of sorting algorithms

- Time Complexity: How the runtime of the algorithm grows with the size of the input.
- Space Complexity: How much extra space the algorithm needs to run.
- Is it adaptive? An adaptive algorithm takes advantage of existing order in its input.
- Is it stable? A stable algorithm maintains the relative order of records with equal keys.
- Is it in place? An in-place algorithm uses a constant amount of extra space.
- Is it recursive? A recursive algorithm solves a problem by solving smaller instances of the same problem.
- Is it internal? An internal algorithm sorts data that fits into the main memory.
